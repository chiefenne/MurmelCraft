# Keyboard map

Generated by `cargo run -p murmel-cli -- keys --markdown > docs/keys.md`
from `crates/murmel-tools/src/commands.rs`; a test fails when it is out of date.
On macOS `Ctrl` is the Command key (⌘ Cmd) and `Alt` the Option key (⌥ Option); the
window names them so. The views match the digit's place on the keyboard, so
Option + 7 works on layouts where it types a character. Every command is also in the command palette
(Ctrl + K), with the palette-only commands below the keyed ones.
