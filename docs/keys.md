# Keyboard map

Generated by `cargo run -p murmel-cli -- keys --markdown > docs/keys.md`
from `crates/murmel-tools/src/commands.rs`; a test fails when it is out of date.
`Ctrl` is the Command key on macOS. Every command is also in the command palette
(Ctrl + K), with the palette-only commands below the keyed ones.
