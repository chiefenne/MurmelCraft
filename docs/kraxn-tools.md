# Kraxn tools

Generated by `cargo run -p kraxn -- tools --markdown`; a test checks it.
Every tool takes JSON and answers with a `kraxn.result` envelope:
`kraxn call TOOL --input '{...}'`.

| Tool | What it does | Input | Changes |
|---|---|---|---|
| `system.detect` | The system, its folders for both scopes, whether Kraxn runs as administrator and whether a desktop is there. | none | nothing |
| `catalogue.list` | The products Kraxn installs, with their programs and source-build needs. | none | nothing |
| `release.list` | The releases of a product, newest first, and whether each has a file for this system. | product: murmelcraft, koflcraft or foehncraft; offline_dir: a folder of downloaded files (optional) | nothing |
| `plan.check` | Checks a plan and returns its steps, with the ones that need administrator rights marked, the tools found (a source build's, Python, ffmpeg) and how each missing one gets installed (`blocked` when only you can), and `notes` on what an offline install leaves out, without running anything. | plan: the plan (as in a plan file) | nothing |
| `plan.apply` | Runs a plan: the missing tools, download, SHA-256 check (or, for a source build, the source and cargo, with cargo's output as events), install with the Python venv and examples, default version, PATH, the AI assistants' MCP servers, and a start check of each program and server. | plan: the plan (as in a plan file) | files |
| `installed.list` | The installed products and versions of a scope, with the default version. | scope: user or system (default user); prefix: another install root (optional) | nothing |
| `version.activate` | Makes an installed version the default (current, module files, links). | product; version; scope; prefix (optional) | files |
| `version.remove` | Removes an installed version, or the whole product without a version; another version becomes the default. | product; version (optional: all); scope; prefix (optional); dry_run: only list the steps | files |
| `assistants.detect` | The AI assistants Kraxn can register the programs' MCP servers with (Claude Code, Claude Desktop, ChatGPT's Codex, Gemini CLI), whether each is on this computer, its settings file and the servers registered there. | none | nothing |
| `diag.codes` | Every diagnostic code with its meaning. | none | nothing |

## Diagnostic codes

| Code | Meaning |
|---|---|
| `TOOL001` | unknown tool |
| `TOOL002` | the input of a tool is not valid |
| `KRX001` | unknown product (not in the catalogue) |
| `KRX002` | the release has no file for this system, or the version does not exist |
| `KRX003` | a download or the list of releases failed |
| `KRX004` | a downloaded file does not match its SHA-256 sum |
| `KRX005` | no SHA256SUMS.txt lists the file, so it cannot be checked |
| `KRX006` | an archive cannot be read or holds an unsafe path |
| `KRX007` | a file system step failed |
| `KRX008` | a step needs administrator rights and did not get them |
| `KRX009` | the version is not installed |
| `KRX010` | the plan is not valid |
| `KRX011` | the program does not start after the install |
| `KRX012` | the offline folder holds no archive for the product |
| `KRX013` | the version is installed already |
| `KRX014` | this system is not supported |
| `KRX015` | a tool the source build needs is missing and Kraxn cannot install it |
| `KRX016` | a command failed (a tool install, the download of the source or cargo) |
| `KRX017` | an AI assistant named in the plan is not on this computer |
| `KRX018` | an AI assistant's settings file cannot be read or changed |
