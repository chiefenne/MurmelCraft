# MurmelCraft tools

Generated by `murmel commands --markdown`; a test fails when this file is out of date.
Every control of the window calls one of these tools, and `murmel call ID --input FILE`
runs the same ids. Each call returns a `murmelcraft.tool-result` envelope.

| Tool | Version | Action | Summary |
|---|---|---|---|
| `system.info` | 1 | read | Version and platform of this build. |
| `system.commands` | 1 | read | The catalogue of every tool with its input schema. |
| `diag.codes` | 1 | read | The diagnostic codes with their severity, meaning and fix. |
| `mesh.open` | 2 | read | Load a mesh and the mesh-evidence.json beside it, replace the open mesh and fit the view; returns counts, zones, patches and the files read. `path` is a .vtu (KoflCraft's foehncraft.vtu) or an OpenFOAM mesh: a case, constant or polyMesh folder, a .foam file in the case or a polyMesh file (ascii, binary, gzip). |
| `mesh.close` | 1 | read | Drop the open mesh from the session. |
| `mesh.info` | 1 | read | Counts, zones, patches, metadata and evidence of the open mesh. |
| `view.get_camera` | 1 | read | The camera: target, distance, yaw, pitch, roll, the cube view it looks along, projection, eye and viewport. |
| `view.set_camera` | 1 | read | Set any of target, distance, yaw, pitch, roll, projection, field of view and viewport size. |
| `view.orbit` | 2 | read | Turn the camera about the up axis (yaw) and tilt it (pitch), in degrees, about the target or about a world point pivot (the window passes the point under the cursor, or the centre of the shown faces over empty space). |
| `view.pan` | 1 | read | Move the view by a drag in pixels (x right, y down); the scene follows the pointer. |
| `view.zoom` | 1 | read | Scale the camera distance by factor (below 1 zooms in), keeping the point under cursor_ndc (-1..1, y up) in place. |
| `view.fit` | 1 | read | Frame the faces shown, or the shown faces of one item (mesh, zone:<name>, kind:<cell type>, patch:<name>), from the current direction. |
| `view.standard` | 1 | read | Go to one of the 26 view-cube views (faces like front, edges like front_top, corners like front_right_top; parts in any order), iso or home, and fit; the roll is reset, and face views snap to orthographic in perspective_ortho_faces. |
| `view.rotate` | 1 | read | Rotate the scene by deg degrees about a screen axis (x right, y up, z towards the viewer; right-hand rule, so +90 about z turns it counter-clockwise on screen). The view cube's roll arrows send z ±90. |
| `view.screenshot` | 1 | write-files | Render the current view offscreen (wgpu) to a PNG at path; mesh and view set up the session first for one-shot use. |
| `display.render_mode` | 1 | read | Draw the mesh shaded with edges (the default), shaded, as a wireframe of every edge, or as feature edges only (creases over 30 degrees, patch borders, open borders). |
| `display.color_by` | 2 | read | Colour the boundary faces in one colour (solid, the default), by patch, by patch role, by the type of their cell, or by the quality of their cell (metric: non_orthogonality in degrees, skewness, volume_ratio or face_count; worst over the cell's faces, on a ramp over the metric's range). Changing the metric clears the threshold. |
| `display.threshold` | 1 | read | Hide the cells whose quality metric is below value, so only the bad cells and the faces around them show; null shows them again. Switches the colouring to quality (and to metric, if given). |
| `display.set_color` | 1 | read | Set the colour (#RRGGBB) of an item of the open mesh (mesh, zone:<name>, kind:<cell type>, patch:<name>), or null to go back to the colour mode's own; the mesh and zone colours show in solid, a patch colour in solid and patch, a cell-type colour in cell_type. |
| `display.visibility` | 1 | read | Show, hide or isolate items by id (mesh, zone:<name>, kind:<cell type>, patch:<name>, cell:<n>, face:<n>), or show all; isolating cells or faces shows only them. Returns the hidden and isolated items and the visible counts. |
| `clip.set` | 1 | read | Set the clip plane: its normal by axis (x, y, z or view; the half nearer the eye is cut away, so the cut faces the camera) or as a vector, its place by origin or by offset along the normal from the centre of the mesh, the mode (crinkle keeps whole cells, flat slices them), flip (swap the side cut away) and enabled. The side the normal points to is cut away; fields left out keep their value (a new plane: x through the centre, crinkle). |
| `clip.clear` | 1 | read | Remove the clip plane; the whole mesh shows again. |
| `select.item` | 2 | read | Select an item by id (mesh, zone:<name>, kind:<cell type>, patch:<name>, cell:<n>, face:<n>); add puts it beside the selection (Shift; again takes it out). Its faces are tinted, a cell or face is outlined, and inspect.item shows the last one selected. |
| `select.pick` | 1 | read | Select the cell (or, with target face, the face) under a screen point ndc (-1..1, y up), as drawn now (clip and hidden items included); add keeps the selection (Shift). A section of a flat cut picks its cell. Nothing under the point clears the selection unless add. Returns hit and picked. |
| `select.filter` | 1 | read | Choose what a click in the viewport picks: cell (the default) or face. |
| `inspect.at` | 1 | read | What lies under a screen point ndc (-1..1, y up), without selecting: the point, the cell with its type and zone, the face with its patch and role (null when nothing is there). The hover tooltip and the cursor coordinates use it. |
| `inspect.quality` | 1 | read | Statistics of a cell quality metric over all cells (the current one when left out): min, max, mean and a histogram of bins equal-width bins (default 20); with above, the number of cells at or above that value. |
| `select.clear` | 1 | read | Clear the selection. |
| `inspect.item` | 1 | read | The property rows of an item (the selection, or the mesh when nothing is selected): the same data as the Properties panel. |
| `journal.undo` | 1 | read | Undo the last step of the camera or the display (a call of a journalled tool, or one group of calls such as a mouse drag); the selection stays. undone is the tool of the step, null when there was none. |
| `journal.redo` | 1 | read | Redo the last undone step; a new step after an undo drops the steps to redo. redone is the tool of the step, null when there was none. |
| `journal.group` | 1 | read | Open or close a group: the calls inside one group undo as one step (the window groups each mouse gesture and each run of wheel steps). |
| `journal.list` | 1 | read | The steps to undo and to redo (oldest first, by tool), whether a group is open, and how many steps are kept. |
| `settings.get` | 1 | read | The theme, the mesh colours, the navigation bindings, the view cube placement, whether agents may drive the window, the presets and the config folder. |
| `settings.set_theme` | 1 | write-files | Switch the theme live (dark, light, system) and write settings.toml in the config folder. |
| `settings.set_colors` | 1 | write-files | Set the user's mesh colours (#RRGGBB) that replace the built-in ones for every mesh: solid (the default mesh colour), the patch palette, role and cell-type colours, edge darkening, the quality ramp (good to bad); reset goes back to the built-in colours first. Writes settings.toml in the config folder. |
| `settings.set_view_cube` | 1 | write-files | Place the view cube: a corner of the viewport (top_right, top_left, bottom_left, bottom_right), a floating panel dragged anywhere over it (position: top left in pixels from the viewport's top left), or hidden; auto_hide hides it while the pointer is farther than distance_px (0 to 2000) from it. Applied live; writes settings.toml in the config folder. |
| `settings.set_agents` | 1 | write-files | Let agents drive the open window (murmel mcp --live) or stop them: off closes the window's socket and every agent's connection. Applied live; writes settings.toml in the config folder. |
| `settings.set_bindings` | 1 | write-files | Choose a navigation preset (three_button, apple, fusion, paraview) or a custom binding table and write navigation.toml in the config folder. |
| `session.save` | 1 | write-files | Write the session to a .murmel file (JSON, format murmelcraft.session): the mesh (path relative to the file and absolute, SHA-256), the camera, the colour and render mode, the quality metric and threshold, the pick target, the hidden, isolated and selected items and item colours by id, the clip plane, the mesh colours and the view cube placement. |
| `session.load` | 1 | read | Load a .murmel session file: open its mesh unless that mesh is already open (tried relative to the file first, then at its absolute path), then restore the camera, the display, the selection and the clip plane; the mesh colours and the view cube placement apply to this session and are not written to settings.toml. A mesh changed since the save (SESS003) or items it no longer has (SESS004) give warnings. A new journal starts. |

## Diagnostic codes

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `TOOL001` | error | No tool has this id. | Run `murmel commands` for the ids. |
| `TOOL002` | error | The input does not match the tool's input schema. | Compare the input with the schema in `murmel commands`. |
| `VIEW001` | error | The tool needs an open mesh and none is open. | Call mesh.open first, or pass `mesh` to view.screenshot. |
| `VIEW002` | error | No item of the open mesh has this id. | Use `mesh`, `zone:<name>`, `kind:<cell type>` or `patch:<name>`; mesh.info lists the names. |
| `MCP001` | error | The MCP server refused a path outside its read or write roots. | Use a path below a --read-root (files read) or a --write-root (files written), or start the server with more roots. |
| `MCP002` | error | The MCP server could not resolve a path (it does not exist, or its folder does not). | Check the path; relative paths resolve from the first --write-root. |
| `LIVE001` | error | No MurmelCraft window listens for agents (none is open, agents are switched off in its Settings, or the platform has no live bridge yet). | Open MurmelCraft and switch on Settings > Agents > Let agents drive this window, or start the MCP server without --live for a headless session. |
| `LIVE002` | error | The window did not answer the call: the person stopped the agents, the window closed, or it took longer than two minutes. | Check the window; the next call connects again. |
| `LIVE003` | error | The window could not listen for agents: another window listens already, or the socket folder is not private. | Close the other window, or make the socket folder private (chmod 700); MURMEL_LIVE_SOCKET names another socket. |
| `SET001` | error | A settings file could not be written, or no config folder is known. | Set MURMEL_CONFIG_DIR to a writable folder. |
| `SET002` | error | The navigation bindings bind one input to two actions. | Give each gesture, button and modifier combination one action. |
| `SESS001` | error | A session file could not be read, or it is not a MurmelCraft session (format murmelcraft.session 1.x) with valid values. | Check the path; save the session again with session.save. |
| `SESS002` | error | A session file could not be written. | Choose a writable folder. |
| `SESS003` | warning | The session's mesh changed since the session was saved (its SHA-256 differs). | Check the view; save the session again to accept the new mesh. |
| `SESS004` | warning | Items the session names are not in the mesh; they were skipped. | Save the session again to drop them. |
| `MESH001` | error | The mesh file cannot be read (missing, unreadable or not a file). | Check the path and the file permissions. |
| `MESH002` | error | The file is not a VTK XML UnstructuredGrid. | Open a .vtu file such as KoflCraft's foehncraft.vtu. |
| `MESH003` | error | The XML of the file is malformed or an expected element is missing. | Write the file again; it may be truncated. |
| `MESH004` | error | A count the file declares cannot fit in the file size. | The file is truncated or its header is wrong; write it again. |
| `MESH005` | error | A data array has the wrong number of values or a value that is not a number. | Write the file again; it may be truncated or edited by hand. |
| `MESH006` | error | A point, face or cell index is out of range. | The connectivity is broken; write the file again. |
| `MESH007` | error | The data encoding is not supported (appended or compressed data). | Write the file with ascii or uncompressed binary (base64) arrays. |
| `MESH008` | error | The file has a cell type the viewer does not read. | Supported: polyhedron (42), tetra (10), hexahedron (12), wedge (13), pyramid (14), triangle (5), polygon (7), quad (9). |
| `MESH009` | error | The polyhedron face stream (faces, faceoffsets) is broken. | Write the file again; KoflCraft writes the legacy VTK polyhedron layout. |
| `MESH010` | error | The mesh has no volume cells and no boundary faces. | Open a volume mesh. |
| `MESH012` | error | The file has more than one Piece. | Write the mesh as one Piece. |
| `MESH011` | warning | mesh-evidence.json beside the mesh cannot be read; the mesh opens without it. | Write the evidence again with KoflCraft or remove it. |
| `MESH013` | error | The folder holds no OpenFOAM mesh, or the polyMesh lacks one of points, faces, owner, neighbour and boundary. | Open a case folder, its constant folder or the polyMesh folder itself. |
| `MESH014` | error | An OpenFOAM file is malformed: no FoamFile header, or a list or dictionary is broken. | Write the mesh again; the file may be truncated or edited by hand. |
| `MESH015` | error | The OpenFOAM boundary patches do not cover the boundary faces once each (startFace, nFaces). | Check constant/polyMesh/boundary; renumbering or checkMesh shows the faces of each patch. |
| `RENDER001` | error | No GPU adapter was found (no driver, or no software renderer such as Mesa lavapipe). | Install a Vulkan, Metal or DirectX 12 driver; on a headless Linux machine install mesa-vulkan-drivers. |
| `RENDER002` | error | The GPU device could not be created or lost during rendering. | Run again; set WGPU_BACKEND to choose another backend. |
| `RENDER003` | error | The screenshot size is outside 1 to 8192 pixels per side. | Pass width and height between 1 and 8192. |
| `RENDER004` | error | The PNG could not be written. | Check that the folder exists and is writable. |
