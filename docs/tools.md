# MurmelCraft tools

Generated by `murmel commands --markdown`; a test fails when this file is out of date.
Every control of the window calls one of these tools, and `murmel call ID --input FILE`
runs the same ids. Each call returns a `murmelcraft.tool-result` envelope.

| `mesh.open` | 6 | read | Load a mesh and the mesh-evidence.json beside it, replace the open mesh and fit the view; returns counts, zones, patches, the fields read with it and the files read. `path` is a KoflCraft mesh (foehncraft.vtu with its cell and point data as fields, or foehncraft.vtkhdf), a FoehnCraft result (.vtkhdf: mesh and fields in one HDF5 file) or a blocked .vtkhdf of MurmelCraft; it also imports the files of other tools: an OpenFOAM mesh (a case, constant or polyMesh folder, a .foam file in the case or a polyMesh file; ascii, binary, gzip) or a VTK .vtu or .vtkhdf. The files are checked with BLAKE3 (`hash`, the key of each file's digest), or with SHA-256 when the evidence beside them is KoflCraft's format 1.0. In the window the digests are taken after the mesh opens: until they are, `validity` is `checking` and `digest` and the files' digests are empty. `mode` fit (the default) opens the mesh whole when it fits the memory budget (settings.set_memory) and a blocked VTKHDF file (murmel blocks make) that does not as an overview: its boundary only, each cell field on it as the value of the cell behind each face, and `overview` (cells, blocks, memory a whole read needs); whole reads it whole whatever it needs; overview asks for the overview. |

| `field.derive` | 1 | read | Compute a derived field from the open result's fields and add it to them, as if the file had it (colour by it, slice it, iso-surfaces, arrows and streamlines of it; saved in sessions as its recipe and computed again on loading). The quantities and fields are FoehnCraft's names and units; field.catalogue lists each with its formula, unit and inputs. Vortices: vorticity (vector, 1/s), q-criterion, lambda2, enstrophy (½ ω·ω), strain-rate (√(2 S:S)). Pressure: total-pressure (p + ½ ρ u·u), pressure-coefficient ((p − p_ref) / (½ ρ_ref U_ref²)), taken wherever the pressure is. Turbomachinery, in the cells, from the turning zones of rotation (zones: zone, origin, axis, rpm; frame): relative-velocity and frame-velocity (vectors w = c − u, u = Ω × (x − x0)), velocity-radial, velocity-circumferential, velocity-axial, velocity-meridional, relative-velocity-circumferential, flow-angle and relative-flow-angle (°), relative-total-pressure (p + ½ ρ w·w), rothalpy (p/ρ + ½ w·w − ½ u·u); each cell is seen in the frame of the first zone that holds it (the fixed frame outside them), or of frame in every cell. Turbulence, in the cells: dissipation-rate, specific-dissipation-rate, time-scale, length-scale (from k and ω or ε, with C_mu), viscosity-ratio (nu_t / ν), reynolds-stress-xx … -xz (Boussinesq). Wall: wall-distance (exact, from each cell centroid to the nearest face of walls). velocity, pressure, k, dissipation (ω or ε) and nu_t name the input fields; left out, they are found by name. A pressure in m²/s² is kinematic and takes no density; a density field (density, rho) wins over the reference density. reference: density, pressure, velocity, viscosity (kinematic, m²/s) and c_mu; rotation and walls: each left out is the field's own when it is made again, else FoehnCraft's (case.resolved.toml beside the result: [output.reference], [fluid], [turbulence.constants], [[mrf]], [[sliding]], [output] frame, boundaries of type wall), else your defaults (settings.set_default kinds reference and rotation), else built in (air at sea level, 0, the largest speed, C_mu 0.09; every cell about z at 0 rpm; the patches whose role is wall); reference_from and rotation_from say where they came from. Computing a field again replaces it. remove: true removes the derived field (refused while an iso-surface, the arrows or a streamline set is made from it). A field the file already has is not computed again. |

## Diagnostic codes

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `TOOL001` | error | No tool has this id. | Run `murmel commands` for the ids. |
| `TOOL002` | error | The input does not match the tool's input schema. | Compare the input with the schema in `murmel commands`. |
| `VIEW001` | error | The tool needs an open mesh and none is open. | Call mesh.open first, or pass `mesh` to view.screenshot. |
| `VIEW002` | error | No item of the open mesh has this id. | Use `mesh`, `zone:<name>`, `kind:<cell type>` or `patch:<name>`; mesh.info lists the names. |
| `VIEW003` | error | No saved view of the open mesh has this name. | views.list names the saved views. |
| `VIEW004` | error | The view name is empty, longer than 64 characters, holds control characters, or another saved view has it. | Choose another name, or delete the other view first. |
| `CLIP001` | error | No clip plane has this number. | Clip planes count from 1 (clip:1); the clips list of the result names them. |
| `CLIP002` | error | The display has the most clip planes it holds (8). | Remove a clip plane with clip.clear, or change one with clip.set. |
| `SLICE001` | error | No slice has this number. | Slices count from 1 (slice:1); the slices list of the result names them. |
| `SLICE002` | error | The display has the most slices it holds (8; a series counts once). | Remove a slice with slice.clear, change one with slice.set, or make a series (count). |
| `SLICE003` | error | A series has a count outside 1 to 64 or a spacing that is not positive. | Give count 1 to 64, and a positive spacing or none (the planes then spread through the mesh). |
| `ISO001` | error | No iso-surface has this number. | Iso-surfaces count from 1 (iso:1); the isos list of the result names them. |
| `ISO002` | error | The display has the most iso-surfaces it holds (8). | Remove one with iso.clear, or change one with iso.set. |
| `ARROW001` | error | Arrows need a vector field (one with x, y and z components), and the field named or the open mesh has none. | Name a vector field (field.list shows each field's components), or open a result with velocity. |
| `REGION001` | error | No region of interest has this number. | Regions count from 1 (region:1); region.list names them. |
| `REGION002` | error | The region's shape is broken (a size, radius or thickness that is not positive, a zero normal, too many rings) or names a zone, patch or cell the mesh does not have. | mesh.info lists the zones and patches; cells count from 0 to the cell count minus one; sizes must be positive. |
| `REGION003` | error | The display has the most regions it holds (16). | Remove a region with region.clear, or change one with region.set. |
| `BLOCK007` | warning | The mesh is not a blocked VTKHDF file and its whole read needs more memory than the budget; it opened whole. | Convert it once with blocks.make (the window offers to, and settings.set_memory convert_large does it without asking) to a blocked copy that opens as an overview, or raise the memory budget. |
| `REGION004` | error | On a mesh open as an overview, regions are boxes, spheres and slabs: each reads the blocks it touches. A zone, patch or cell region needs the cells read whole. | Draw a box, sphere or slab around what you need, or open the mesh whole (mesh.open with mode whole) if the memory allows. |
| `ARROW002` | error | The arrows' density is outside 4 to 200, or their scale is not above 0 and up to 100. | Give density 4 to 200 (arrows across the mesh's largest extent) and a scale above 0, up to 100. |
| `PARCEL001` | error | No parcels are open. | Open a parcel file (FoehnCraft's spray/parcels_<step>.vtkhdf) with parcels.open. |
| `PARCEL002` | error | The parcel file has no field of this name (to colour by, to size by diameter or to filter by diameter or injector). | The message lists the fields of the file; parcels.open's result lists them too. |
| `PARCEL003` | error | A parcel setting is out of range: a scale not above 0 or above 100, a diameter range not 0 <= min <= max, an unknown colour map or a fixed range not min < max. | Give a scale above 0 up to 100, diameters in metres with min <= max, a map of field.style's list or auto, and min < max. |
| `SERIES001` | error | The time series cannot be read: the path does not exist, the manifest is not foehncraft.series 1 or names a step twice or a step without files, or the folder holds no numbered files. | Give FoehnCraft's series.json or its output folder (fields_<step>.vtkhdf, spray/parcels_<step>.vtkhdf). |
| `SERIES002` | error | No time series is open. | Open a series.json or an output folder with series.open. |
| `SERIES003` | error | The series has no such step, index or time, or the rate is outside 0.1 to 60 steps a second. | series.open's result gives the count, the first and last step and the times. |
| `SERIES004` | error | The colour range over the steps was not read: the field is not one of the open mesh's, or the reading was cancelled. | Colour by a field of the open mesh (field.list) and read the range again. |
| `CHART001` | error | The tables of a run cannot be read: the path does not exist, the folder has neither datums.csv nor spray.csv, or a table is not of its format version 1 (foehncraft-datums, foehncraft-spray), has no header or a short row before its last. | Give the output folder of a transient FoehnCraft run with [[datum]] or [spray] (or a file in it); the message names the table and what is wrong. |
| `CHART002` | error | No run is charted. | Open an output folder with charts.open; series.open opens the charts of its folder too. |
| `CHART003` | error | The chart cannot be drawn as asked: an unknown datum, injector or column, more series than the six hues, columns of different units on one axis, a histogram of several datums or none, a size or scale out of range, or a file that is not .png or .svg. | The message lists what the run has; charts.open's result lists datums, injectors and tables. Chart quantities of other units apart. |
| `STREAM001` | error | No streamline set has this number, or the display has the most it holds (8). | Sets count from 1 (stream:1); the streams list of the result names them. Remove one with stream.clear to add another. |
| `STREAM002` | error | A streamline setting is out of range (count outside 1 to 1000, a length or radius not above 0, a line of one point, a zero normal), names a patch the mesh does not have, or belongs to another seed shape than the set's. | Give count 1 to 1000 and positive lengths; mesh.info lists the patches; name the shape with seed to change it (line: from, to; sphere: centre, radius; patch: patch; plane: origin, normal). |
| `STREAM003` | error | Streamlines follow a vector field (one with x, y and z components), and the field named or the open mesh has none. | Name a vector field (field.list shows each field's components), or open a result with velocity. |
| `MCP001` | error | The MCP server refused a path outside its read or write roots. | Use a path below a --read-root (files read) or a --write-root (files written), or start the server with more roots. |
| `MCP002` | error | The MCP server could not resolve a path (it does not exist, or its folder does not). | Check the path; relative paths resolve from the first --write-root. |
| `LIVE001` | error | No MurmelCraft window listens for agents (none is open, agents are switched off in its Settings, or the platform has no live bridge yet). | Open MurmelCraft and switch on Settings > Agents > Let agents drive this window, or start the MCP server without --live for a headless session. |
| `LIVE002` | error | The window did not answer the call: the person stopped the agents, the window closed, or it took longer than two minutes. | Check the window; the next call connects again. |
| `LIVE003` | error | The window could not listen for agents: another window listens already, or the socket folder is not private. | Close the other window, or make the socket folder private (chmod 700); MURMEL_LIVE_SOCKET names another socket. |
| `SET001` | error | A settings file could not be written, or no config folder is known. | Set MURMEL_CONFIG_DIR to a writable folder. |
| `SET002` | error | The navigation bindings bind one input to two actions. | Give each gesture, button and modifier combination one action. |
