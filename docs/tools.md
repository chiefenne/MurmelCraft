# MurmelCraft tools

Generated by `murmel commands --markdown`; a test fails when this file is out of date.
Every control of the window calls one of these tools, and `murmel call ID --input FILE`
runs the same ids. Each call returns a `murmelcraft.tool-result` envelope.

| Tool | Version | Action | Summary |
|---|---|---|---|
| `system.info` | 1 | read | Version and platform of this build. |
| `system.commands` | 1 | read | The catalogue of every tool with its input schema. |
| `diag.codes` | 1 | read | The diagnostic codes with their severity, meaning and fix. |
| `mesh.open` | 3 | read | Load a mesh and the mesh-evidence.json beside it, replace the open mesh and fit the view; returns counts, zones, patches, the fields read with it and the files read. `path` is a .vtu (KoflCraft's foehncraft.vtu, with its cell and point data as fields), a FoehnCraft result (.vtkhdf: mesh and fields in one HDF5 file) or an OpenFOAM mesh: a case, constant or polyMesh folder, a .foam file in the case or a polyMesh file (ascii, binary, gzip). |
| `mesh.close` | 1 | read | Drop the open mesh from the session. |
| `mesh.info` | 1 | read | Counts, zones, patches, metadata and evidence of the open mesh. |
| `view.get_camera` | 1 | read | The camera: target, distance, yaw, pitch, roll, the cube view it looks along, projection, eye and viewport. |
| `view.set_camera` | 1 | read | Set any of target, distance, yaw, pitch, roll, projection, field of view and viewport size. |
| `view.orbit` | 2 | read | Turn the camera about the up axis (yaw) and tilt it (pitch), in degrees, about the target or about a world point pivot (the window passes the point under the cursor, or the centre of the shown faces over empty space). |
| `view.pan` | 1 | read | Move the view by a drag in pixels (x right, y down); the scene follows the pointer. |
| `view.zoom` | 1 | read | Scale the camera distance by factor (below 1 zooms in), keeping the point under cursor_ndc (-1..1, y up) in place. |
| `view.fit` | 1 | read | Frame the faces shown, or the shown faces of one item (mesh, zone:<name>, kind:<cell type>, patch:<name>), from the current direction. |
| `view.standard` | 1 | read | Go to one of the 26 view-cube views (faces like front, edges like front_top, corners like front_right_top; parts in any order), iso or home, and fit; the roll is reset, and face views snap to orthographic in perspective_ortho_faces. |
| `view.rotate` | 1 | read | Rotate the scene by deg degrees about a screen axis (x right, y up, z towards the viewer; right-hand rule, so +90 about z turns it counter-clockwise on screen). The view cube's roll arrows send z ±90. |
| `views.save` | 1 | read | Save the camera as a named view of the open mesh (a bookmark in the model tree); name left out takes the first free "View N", a name that exists gets the current camera. Saved views go into session files; opening another mesh drops them. |
| `views.go` | 1 | read | Go to a saved view: its target, distance, angles, roll and projection (the window flies there). |
| `views.rename` | 1 | read | Rename a saved view; the new name must be free. |
| `views.delete` | 1 | read | Delete a saved view (undo brings it back). |
| `views.list` | 1 | read | The saved views of the open mesh, in the order they were saved, with their cameras. |
| `view.screenshot` | 1 | write-files | Render the current view offscreen (wgpu) to a PNG at path; mesh and view set up the session first for one-shot use. |
| `export.image` | 1 | write-files | Export the view as a PNG at path for reports and posters: the viewport's size times scale (or width and height in pixels), lines, legend and text grown with the scale so the picture looks like the window, the colour legend (top left) and the axis triad (bottom left) each optional, the background transparent if asked, the resolution (dpi) stored for print. |
| `export.movie` | 1 | write-files | Export a movie at path (.mp4, .gif, or a folder of PNG frames) with the look of export.image (size, scale, legend, axes, lines): the camera turning about its target (orbit; a whole turn loops), a clip plane sweeping through the mesh (clip), or a flight through saved views that eases into each and holds there (views). MP4 is H.264 made by the ffmpeg installed on the machine (EXPORT002 without one); GIF and PNG are written by MurmelCraft. The view stays as it was. |
| `display.render_mode` | 1 | read | Draw the mesh shaded with edges (the default), shaded, as a wireframe of every edge, or as feature edges only (creases over 30 degrees, patch borders, open borders). |
| `display.color_by` | 3 | read | Colour the boundary faces in one colour (solid, the default), by patch, by patch role, by the type of their cell, by the cell zone of their cell (zone; on the patch palette, zone colours set with display.set_color win), by the quality of their cell (metric: non_orthogonality in degrees, skewness, volume_ratio or face_count; worst over the cell's faces, on a ramp over the metric's range), or by a field of the results (field: its name, default the one chosen before or the file's first; component of a vector: magnitude, x, y or z). Changing the metric clears the threshold. A field is drawn in its style (field.style). |
| `field.list` | 1 | read | The fields of the open mesh (name, location cell, point or boundary, components, unit, count, range per component, style), the result's time, step or iteration and file attributes, the colour maps, and the field colouring shown now (colour range, map, style). |
| `field.style` | 1 | read | Set how a field is drawn (the one chosen now, or `field`): mode flat (one colour per cell, the solver's values), smooth (node values by inverse distance weighting, the default) or banded (bands steps, 2 to 64, default 12); contour lines on or off (lines) and how many (line_count, 1 to 64, default 12, splitting the range into line_count + 1 even steps); the colour map (map: an id of field.list or auto, which takes viridis, or cool_warm for a range centred on zero) and reverse; the colour range (range: field, the whole field's min to max, the default; shown, what is drawn now; symmetric, -max|v| to +max|v|; fixed, min to max, a bound left out keeping the range shown now). reset starts from the default style. Each field keeps its own style. |
| `display.threshold` | 1 | read | Hide the cells whose quality metric is below value, so only the bad cells and the faces around them show; null shows them again. Switches the colouring to quality (and to metric, if given). |
| `display.set_color` | 1 | read | Set the colour (#RRGGBB) of an item of the open mesh (mesh, zone:<name>, kind:<cell type>, patch:<name>), or null to go back to the colour mode's own; the mesh and zone colours show in solid, a zone colour also in zone, a patch colour in solid and patch, a cell-type colour in cell_type. |
| `display.visibility` | 1 | read | Show, hide or isolate items by id (mesh, zone:<name>, kind:<cell type>, patch:<name>, cell:<n>, face:<n>), or show all; isolating cells or faces shows only them. Returns the hidden and isolated items and the visible counts. |
| `clip.set` | 2 | read | Set a clip plane (plane: its number, clip:1 is the first; left out: the current plane, the one selected last or else added last; new: add one, up to 8): its normal by axis (x, y, z or view; the half nearer the eye is cut away, so the cut faces the camera) or as a vector, its place by origin or by offset along the normal from the centre of the mesh, the mode (crinkle keeps whole cells, flat slices them), flip (swap the side cut away) and enabled. The side the normal points to is cut away; fields left out keep their value (a new plane: x through the centre, crinkle). A cell shows when every enabled plane keeps it; flat planes slice in the order they were added. |
| `clip.rotate` | 1 | read | Tilt a clip plane (plane: its number; left out: the current plane) by deg degrees about an axis through pivot (right-hand rule). The axis is a screen axis (x right, y up, z towards the viewer, as in view.rotate) or a world vector; the pivot defaults to the centre of the plane inside the mesh's box, so the plane stays in the mesh. The window's tilt arcs and Alt + arrow keys call it. |
| `clip.clear` | 2 | read | Remove a clip plane (plane: its number; left out: the current plane), or all of them (all); the planes after it move up one. |
| `slice.set` | 1 | read | Add or change a slice (slice: its number, slice:1 is the first; left out: the current slice, the one selected last or else added last; new: add one, up to 8): a plane through the cells shown that cuts nothing away and draws their sections in the colours of the mesh (the field shown in its style, or the colour mode's cell colours). Its normal by axis (x, y, z or view) or as a vector, its place by origin or by offset along the normal from the centre of the mesh, flip and enabled, as for clip.set. A series: count planes (1 to 64) spacing apart along the normal, the middle one at the origin; a count without spacing spreads them evenly through the mesh. While slices or iso-surfaces show, the mesh draws as a faint outline (display.mesh_look). Clip planes cut slices too. |
| `slice.rotate` | 1 | read | Tilt a slice (slice: its number; left out: the current slice) by deg degrees about an axis through pivot, as clip.rotate tilts a clip plane: a screen axis (x right, y up, z towards the viewer) or a world vector; the pivot defaults to the centre of the plane inside the mesh's box. The window's tilt arcs call it. |
| `slice.clear` | 1 | read | Remove a slice (slice: its number; left out: the current slice), or all of them (all); the slices after it move up one. |
| `iso.set` | 1 | read | Add or change an iso-surface (iso: its number, iso:1 is the first; left out: the current one; new: add one, up to 8): the surface where field (with component for a vector; left out: its own field, else the field shown, else the file's first) takes value (left out: its own value, or the middle of the field's range for a new one or a new field). color solid gives it a colour of its own (the patch hues in turn, or display.set_color on iso:<n>); field colours it by the field on the colour bar in that field's style. Made by marching tetrahedra in every cell shown (cell centroid, face centres and nodes), so it closes across cells; clip planes cut it. |
| `iso.clear` | 1 | read | Remove an iso-surface (iso: its number; left out: the current one), or all of them (all); those after it move up one. |
| `display.mesh_look` | 1 | read | What the mesh looks like while slices or iso-surfaces show: outline (the default: its feature edges only, faint, so what is inside stands out; a click then picks the slices) or faces (as the render mode says). |
| `select.item` | 2 | read | Select an item by id (mesh, zone:<name>, kind:<cell type>, patch:<name>, cell:<n>, face:<n>); add puts it beside the selection (Shift; again takes it out). Its faces are tinted, a cell or face is outlined, and inspect.item shows the last one selected. |
| `select.pick` | 1 | read | Select the cell (or, with target face, the face) under a screen point ndc (-1..1, y up), as drawn now (clip and hidden items included); add keeps the selection (Shift). A section of a flat cut picks its cell. Nothing under the point clears the selection unless add. Returns hit and picked. |
| `select.filter` | 1 | read | Choose what a click in the viewport picks: cell (the default) or face. |
| `inspect.at` | 1 | read | What lies under a screen point ndc (-1..1, y up), without selecting: the point, the cell with its type and zone, the face with its patch and role (null when nothing is there). The hover tooltip and the cursor coordinates use it. |
| `inspect.quality` | 1 | read | Statistics of a cell quality metric over all cells (the current one when left out): min, max, mean and a histogram of bins equal-width bins (default 20); with above, the number of cells at or above that value. |
| `select.clear` | 1 | read | Clear the selection. |
| `inspect.item` | 1 | read | The property rows of an item (the selection, or the mesh when nothing is selected): the same data as the Properties panel; with results, the field values of a cell, a boundary face (its boundary values and its cell's) or a probe (interpolated at its point). |
| `journal.undo` | 1 | read | Undo the last step of the camera or the display (a call of a journalled tool, or one group of calls such as a mouse drag); the selection stays. undone is the tool of the step, null when there was none. |
| `journal.redo` | 1 | read | Redo the last undone step; a new step after an undo drops the steps to redo. redone is the tool of the step, null when there was none. |
| `journal.group` | 1 | read | Open or close a group: the calls inside one group undo as one step (the window groups each mouse gesture and each run of wheel steps). |
| `journal.list` | 1 | read | The steps to undo and to redo (oldest first, by tool), whether a group is open, and how many steps are kept. |
| `settings.get` | 1 | read | The theme, the mesh colours, the navigation bindings, the view cube placement, whether agents may drive the window, the presets and the config folder. |
| `settings.set_theme` | 1 | write-files | Switch the theme live (dark, light, system) and write settings.toml in the config folder. |
| `settings.set_colors` | 1 | write-files | Set the user's mesh colours (#RRGGBB) that replace the built-in ones for every mesh: solid (the default mesh colour), the patch palette, role and cell-type colours, edge darkening, the quality ramp (good to bad), the clip handles per theme (gizmo.dark and gizmo.light: slide arrow and tilt arcs), the measurements per theme (measure.dark and measure.light: line, probe, halo); reset goes back to the built-in colours first. Writes settings.toml in the config folder. |
| `settings.set_view_cube` | 1 | write-files | Place the view cube: a corner of the viewport (top_right, top_left, bottom_left, bottom_right), a floating panel dragged anywhere over it (position: top left in pixels from the viewport's top left), or hidden; auto_hide hides it while the pointer is farther than distance_px (0 to 2000) from it. Applied live; writes settings.toml in the config folder. |
| `settings.set_agents` | 1 | write-files | Let agents drive the open window (murmel mcp --live) or stop them: off closes the window's socket and every agent's connection. Applied live; writes settings.toml in the config folder. |
| `settings.set_bindings` | 1 | write-files | Choose a navigation preset (three_button, apple, fusion, paraview) or a custom binding table and write navigation.toml in the config folder. |
| `session.save` | 1 | write-files | Write the session to a .murmel file (JSON, format murmelcraft.session): the mesh (path relative to the file and absolute, SHA-256), the camera, the colour and render mode, the quality metric and threshold, the pick target, the hidden, isolated and selected items and item colours by id, the clip plane, the saved views, the field shown and each field's style, the mesh colours and the view cube placement. |
| `session.load` | 1 | read | Load a .murmel session file: open its mesh unless that mesh is already open (tried relative to the file first, then at its absolute path), then restore the camera, the display, the selection and the clip plane; the mesh colours and the view cube placement apply to this session and are not written to settings.toml. A mesh changed since the save (SESS003) or items it no longer has (SESS004) give warnings. A new journal starts. |
| `measure.snap` | 1 | read | The point a click at a screen point would measure from: the face under it gives its nodes, edge midpoints, centre (and its cell's centre), projected to the screen; the first kind in the order node, edge_midpoint, face_centre, cell_centre, edge, surface with a candidate within radius_px (default 12) wins; snap lists the kinds allowed (default all but cell_centre). Null over empty space. Changes nothing. |
| `measure.add` | 1 | read | Measure in the open mesh and keep the result as a tree item measure:<n>: a distance between two points (with dx, dy, dz) or the angle at the second of three points (degrees). Each point is a screen point snapped as measure.snap does, typed coordinates, a node, the midpoint of two nodes, a face centre or a cell centre. Kept in session files; undo removes it. |
| `measure.rename` | 1 | read | Name a measurement or a probe (measure:<n>, probe:<n>); a null name goes back to "Distance n", "Angle n" or "Probe n". |
| `measure.remove` | 1 | read | Remove measurements and probes: the items named (measure:<n>, probe:<n>), or all of them. Undo brings them back. |
| `measure.list` | 1 | read | The measurements (value, unit, points and what they snapped to) and the probes (point, cell and what it reads) of the open mesh. |
| `probe.add` | 1 | read | Place a probe (tree item probe:<n>) that reads the cell holding a point: the point, the cell, its type, zone, centroid and the distance to it, its volume and worst non-orthogonality and skewness, and with results every field's value at the point (inverse distance weighted from the cell's nodes). The point is given as for measure.add; typed coordinates are located in the mesh (generalised winding number). Kept in session files; undo removes it. |
| `probe.at` | 1 | read | What a probe at a point would read, without keeping it: the point given as for measure.add, the cell holding it and that cell's values. Changes nothing. |

## Diagnostic codes

| Code | Severity | Meaning | Fix |
|---|---|---|---|
| `TOOL001` | error | No tool has this id. | Run `murmel commands` for the ids. |
| `TOOL002` | error | The input does not match the tool's input schema. | Compare the input with the schema in `murmel commands`. |
| `VIEW001` | error | The tool needs an open mesh and none is open. | Call mesh.open first, or pass `mesh` to view.screenshot. |
| `VIEW002` | error | No item of the open mesh has this id. | Use `mesh`, `zone:<name>`, `kind:<cell type>` or `patch:<name>`; mesh.info lists the names. |
| `VIEW003` | error | No saved view of the open mesh has this name. | views.list names the saved views. |
| `VIEW004` | error | The view name is empty, longer than 64 characters, holds control characters, or another saved view has it. | Choose another name, or delete the other view first. |
| `CLIP001` | error | No clip plane has this number. | Clip planes count from 1 (clip:1); the clips list of the result names them. |
| `CLIP002` | error | The display has the most clip planes it holds (8). | Remove a clip plane with clip.clear, or change one with clip.set. |
| `SLICE001` | error | No slice has this number. | Slices count from 1 (slice:1); the slices list of the result names them. |
| `SLICE002` | error | The display has the most slices it holds (8; a series counts once). | Remove a slice with slice.clear, change one with slice.set, or make a series (count). |
| `SLICE003` | error | A series has a count outside 1 to 64 or a spacing that is not positive. | Give count 1 to 64, and a positive spacing or none (the planes then spread through the mesh). |
| `ISO001` | error | No iso-surface has this number. | Iso-surfaces count from 1 (iso:1); the isos list of the result names them. |
| `ISO002` | error | The display has the most iso-surfaces it holds (8). | Remove one with iso.clear, or change one with iso.set. |
| `MCP001` | error | The MCP server refused a path outside its read or write roots. | Use a path below a --read-root (files read) or a --write-root (files written), or start the server with more roots. |
| `MCP002` | error | The MCP server could not resolve a path (it does not exist, or its folder does not). | Check the path; relative paths resolve from the first --write-root. |
| `LIVE001` | error | No MurmelCraft window listens for agents (none is open, agents are switched off in its Settings, or the platform has no live bridge yet). | Open MurmelCraft and switch on Settings > Agents > Let agents drive this window, or start the MCP server without --live for a headless session. |
| `LIVE002` | error | The window did not answer the call: the person stopped the agents, the window closed, or it took longer than two minutes. | Check the window; the next call connects again. |

| `SET002` | error | The navigation bindings bind one input to two actions. | Give each gesture, button and modifier combination one action. |
| `EXPORT001` | error | An export setting is out of range (scale, line width, dpi). | Use a scale of 0.25 to 8, a line width of 1 to 32 pixels and a dpi of 1 to 10000; a movie 1 to 60 frames a second and at most 36000 frames, an MP4 without transparency. |
| `EXPORT002` | error | An MP4 needs ffmpeg, and none was found (MURMEL_FFMPEG, PATH, /opt/homebrew/bin, /usr/local/bin). | Install ffmpeg (macOS: brew install ffmpeg), set MURMEL_FFMPEG to its path, or write a GIF or PNG frames. |
