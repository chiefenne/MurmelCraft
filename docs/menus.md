# Menus

Generated by `cargo run -p murmel-cli -- menus --markdown > docs/menus.md`
from `crates/murmel-tools/src/menus.rs`; a test fails when it is out of date.
The menus hold the common commands; every command, in a menu or not, is also
in the command palette (Ctrl + K) and keeps its keys ([keys.md](keys.md)). On macOS
`Ctrl` is the Command key.

- Open OpenFOAM case folder… `Ctrl + Shift + O` → `mesh.open`
