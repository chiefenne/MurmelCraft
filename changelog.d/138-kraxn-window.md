- **Kraxn window.** `kraxn` now opens a window that walks through the
  install one page at a time (for whom, where from, which programs and
  versions, PATH, every step with the administrator steps marked), shows
  each step's result and the checks, saves the answers as a plan file, and
  manages installed versions (default, remove). Dark and light theme from
  MurmelCraft's design tokens, every control named for screen readers
  ([docs/kraxn.md](docs/kraxn.md)).
