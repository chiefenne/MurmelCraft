- **Kraxn sets up the AI assistants.** It finds Claude Code, Claude
  Desktop, ChatGPT's Codex and Gemini CLI, registers each installed
  program's MCP server under its README name (`murmelcraft-live`,
  `koflcraft`, `foehn`) with the ones you choose, copies every settings
  file first, starts each server once at the end, and takes the servers
  out again when a program is removed ([docs/kraxn.md](docs/kraxn.md)).
