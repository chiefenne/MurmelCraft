- **Kraxn adds MurmelCraft to the menu.** An install of MurmelCraft gets a
  menu entry (Linux desktop file, `MurmelCraft.app` in Applications, a
  Start menu shortcut) and, on Linux and Windows, opens `.murmel` files
  by default and offers itself for `.vtu` and `.vtkhdf` under "Open
  with"; removing MurmelCraft takes them away
  ([docs/kraxn.md](docs/kraxn.md)).
