- **Shared Linux install: ARM archives and a safer PATH switch.** `tools/install-shared.sh` now downloads the archive for the machine it runs on: `linux-x86_64`, or `linux-aarch64` on 64-bit ARM. The `env.sh` it writes takes the other versions off PATH with a loop over PATH's parts, as Kraxn's does. Before, it used a glob, which zsh stopped at when a version had no venv. It also read a PATH folder with `*`, `?` or `[` in its name as a pattern.
