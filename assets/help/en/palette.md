The command palette finds any command by typing a few letters of its name or group. Every command of MurmelCraft is in it, also those in no menu and with no key.

<!-- more -->

## Command palette

Type words in any order: "slice x" finds *Slice normal to X*. Arrows choose, Enter runs, Esc closes. The palette shows each command's key, so it is also a way to learn them. Commands that do not apply now (nothing selected) are left out.
